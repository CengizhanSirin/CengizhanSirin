## 🚀 Featured Projects

### [ECommerceOrderManagementAPI](https://github.com/CengizhanSirin/ECommerceOrderManagementAPI)

An e-commerce backend built with .NET 10 and Clean Architecture.

- CQRS with MediatR
- Domain rules for inventory, shopping carts, orders, coupons and payments
- JWT authentication and refresh tokens
- Entity Framework Core and SQL Server
- Iyzico payment integration
- RabbitMQ and Outbox pattern
- Docker Compose
- 37 unit tests and 3 integration tests

### [ECommerceAPI](https://github.com/CengizhanSirin/ECommerceAPI)

A RESTful e-commerce API developed with .NET 10 and Onion Architecture.

- Product, category, brand, cart, address and order management
- ASP.NET Core Identity and JWT authentication
- FluentValidation and Result Pattern
- Soft delete and transaction management
- 136 unit tests

### [ProductAPI](https://github.com/CengizhanSirin/ProductAPI)

A product management REST API created to practice CRUD operations and core backend development concepts.
